Floorplan Retargeting：die 收缩下的宏布局迁移

Track B 候选题，工业界口径的重新定义。"用户已经有一版满意的宏布局，后来 die 要缩小，希望宏保持相对位置和大致分布"，在工业流程里对应的是 floorplan retargeting / floorplan migration：一份既有 floorplan 里沉淀了大量设计意图（相对位置、贴边、阵列、通道、电源网格与引脚关系），外框变了，意图要保住。与同事确认后的口径：宏之间的两两位置关系不能变，要做的是宏合法化和引脚合法化。下面先说工业界把它当什么问题、怎么解，再给出正式定义，最后是交互演示，可在合成案例 synth_ring（117 宏、17 组、边界堆满一圈、多组向内堆叠）和 bp_fe、bp_be、bp_multi、swerv、ariane133（132 宏）五个专家布局之间切换。

一、工业界里这是什么问题

场景发生了什么为什么不能重新布出处
成本导向的衍生芯片 / 最小可行 die 探索同一工艺节点，砍功能或提高利用率后把 die 缩小以降低单颗成本；工具"自动分析约束、找出最小可布线 die 尺寸"，把 I/O 单元按比例重新塞进缩小后的边界，同时"保持原来的边、相对顺序和对齐"。pad ring、bump、封装已定；宏布局是时序收敛和电源网格的基础。Synopsys 专利 US 8037442
层次化 SoC 的分区重预算"某个 block 需要比预算略多的面积，芯片架构师就得改动周围 block 的位置"，连带电源环、JTAG、pin 都要重调；一次迭代 6 小时。每次 floorplan 变动都要重做 PG/时钟预布线，人工返工是主要成本。Design-Reuse《Dynamic Floorplanning》；Design-Reuse《Floorplan Guidelines》
跨节点迁移时的非均匀缩放逻辑缩 0.5×，SRAM 只缩 0.7 到 0.8×，模拟/PHY 几乎不缩；等价于"外框相对宏变小"。深亚微米下"shrink 几乎不可行，必须做非线性 relayout"。硬 IP 是固定 GDS，尺寸、形状、内部布线都不能改。SemiEngineering《SRAM Scaling Issues》；Design-Reuse《Hard IP》；TSMC 分区缩放专利 US 10685161
硬 IP / 模拟版图的 retargeting以旧版图为输入，用约束图模板保住"设计者的物理智慧"（对称、匹配、拓扑），再在新规则/新面积下求解。重新布局会丢失匹配与对称等隐性意图。Analog Layout Retargeting（Springer）；SMT-based retargeting（2025）

四个场景的共同内核：输入是一份带意图的 floorplan，输出外框变了，宏尺寸不变（或按各自因子缩放），要在新外框里给出合法布局，并尽量少破坏原意图。这正是用户描述的 macro shrinking。

二、工业界怎么解

1. 相对 floorplan 约束（EDA 工具内建）

Cadence Innovus 的 create_relative_floorplan：宏相对参考对象（core 边界、其他宏、group）以偏移量定位，"参考对象移动，宏跟着移动"，明确面向"层次化与衍生设计"。Design-Reuse 的 Dynamic Floorplanning 用 {参考点, 象限} + 偏移描述每个宏，用 reshape / relativereshape / reshapebetween 描述软块尺寸，"顶层 floorplan 按约束的重要性顺序手写"，尺寸变化后重放脚本即可再生，一次迭代从 6 小时降到 10 分钟。

2. 约束图压缩 + 留白按比例再分配

把布局转成水平/垂直约束图（sequence pair 的等价物），最长路径给出最小外框；若新外框放得下，把松弛量按原始通道宽度的比例分回去。IBM 的留白再分配专利给出公式：新弧长 = 原弧长 × 最小路径松弛 / 最大路径权重。这就是"保持大致分布"的精确版本。

3. 约束驱动的 floorplan 修复（FLOORIST）

把每对宏的关系写成 L/R/A/B 四选一的"松弛约束图"，只改造成冲突的宏（沿关键路径找 culprits），支持固定外框、区域、邻近、对齐约束；论文原话："The original solution should be preserved as much as possible"，评价用重叠率、HPWL、位移。

4. 现代 floorplanning 的约束分类

Young/Chu 与 Chen/Chang 的体系：preplaced、range、boundary、alignment、abutment、clustering、fixed-outline、rectilinear；fixed-outline floorplanning（Adya–Markov）是"给定外框内重排"的标准问题。

5. 阵列规整性（2026）

MacroAgent 把宏合法化的目标写成位移 + 规整性，规整性指数 R = Cmin/Cactual（理想方阵的通道数 / 实际通道数）；同尺寸宏先聚类、再按模板网格匹配。这给"bank 阵列不能被打散"提供了可计算的指标。

三、正式定义（严格版：宏两两关系不变，宏合法化 + 引脚合法化）

Floorplan Retargeting under Outline Reduction。给定参考 floorplan F0：core O0、die D0 及其边界上的 IO 引脚（边、位置、层）、宏集合 M（尺寸、位置、朝向固定）、网表；目标外框 O1/D1（等比或非等比缩小）；物理规则 R，其中最小通道是客户给定的约束，作为 case 参数随题给出，分三个值：宏与宏之间 cmin、宏与 core 边之间 cedge、宏引脚面前方 cpin（默认 10 / 10 / 10 µm，给电源条与引脚布线）；F0 中已经贴合的宏（间隙 ≤ 3 µm，阵列或叠放）视为刻意贴合，作为一个刚性块保持原样，是唯一的例外。其余规则：site/row 网格（0.19 / 1.4 µm）、引脚层轨道（metal5/metal6，0.28 µm）、引脚最小间距 2 轨（0.56 µm）、角落避让。求 O1 内每个宏的位置和 D1 边界上每个引脚的位置。

不变量（硬约束）

  • 宏两两位置关系不变：任意两个宏的左右 / 上下关系（等价于 sequence pair）与 F0 完全一致；宏尺寸、朝向不变。这一条来自同事确认的工业做法：die 收缩是 floorplan 的复用，不是重新布局。
  • 宏合法化（含客户最小通道）：不重叠、在 core 内、对齐网格；任意两个不贴合的宏之间通道 ≥ cmin，引脚面前方 ≥ cpin，宏与 core 边之间 ≥ cedge（原来贴边的仍贴边，间隙为 0）；F0 里刻意贴合的宏保持贴合。参考布局 F0 本身必须先满足这套规则，否则先做一次 s = 1 的合法化。
  • 引脚合法化：每个 IO 引脚在新 die 的边界上，同一条边、同样的先后顺序；落在该层轨道上；相邻引脚 ≥ 2 轨；不在贴边宏的正前方（ORFS 的 pin placer 也这样做，实测五个设计里没有一个引脚落在贴边宏前面）；不在角落。

允许的"微调"只有两类：通道宽度和边缘留白在客户最小值之上重新分配；引脚沿边滑动。不重折阵列、不翻转关系、不并拢块、不把通道压到客户规则以下。

可行性：宏关系固定后，每个方向的最小外框由约束图的最长路径唯一给出；每条边的引脚容量由空闲轨道数给出。任一超出即"该目标不可行"，case 生成器拒绝，并报告最大可行等比缩比 s*（二分求得）。这与 Synopsys 专利里"找最小可布线 die"的做法一致。

隐藏参考 F1*：由第五节的算法生成，满足以上全部条件；真实设计还要过固定后端流程（tc_flow 探针）确认可布线、时序不劣化。agent 不必复现参考解，只要满足同样的不变量。

四、交互演示（合成案例 + 五个设计的专家布局，可切换）

synth_ring 是为这道题设计的合成案例：core 1560×1360 µm，117 宏、17 组，尺寸从 30×25 到 240×190 µm；四角各一块（PLL、ROM、PHY、eFuse），四条边被 L2、TLB、dcache、tag、btb、icache、寄存器堆、FIFO、DMA 堆满一圈，其中 L2 和 icache 向内堆两层、FIFO 向内堆三层；内部另有 scratchpad 2×2、NoC 缓冲一列、CAM 3×3、misc 一行。宏面积占核心 41.6%，缩到 85% 后为 58%。

② 直接等比缩放坐标

④ 专家参考解（fr_retarget，严格模式 + 引脚合法化）

严格模式：宏对关系全部保持，约束图最长路径判可行，逐轴 LP 按比例分配通道，宏合法化后再做引脚合法化（同边同序、轨道对齐、≥2 轨、避开贴边宏）。滑块取最近的预算档位；橙色密度条 = 引脚。

五、参考解生成算法（fr_retarget 严格模式：合法、保通道、保关系、引脚合法）

参考解必须满足的专家标准

  • 宏关系不变：约束图（每对块一个 L/R/A/B 关系）从 F0 提取后固定不动。
  • 宏合法 + 客户最小通道：无重叠、在核心内、对齐 site/row；不贴合的宏之间 ≥ cmin、引脚面前方 ≥ cpin、到 core 边 ≥ cedge；F0 中贴合的宏作为刚性块保持原间隙；贴边宏仍贴边；朝向不变。
  • 通道按比例：通道宽度尽量 ∝ 原宽 × 缩比，偏差分摊到所有通道。
  • 引脚合法：同边同序、轨道对齐、≥ 2 轨、避开贴边宏正前方与角落；位置尽量 ∝ 原位置。
  • 不可行判定：放不下就拒绝，报告最大可行缩比 s*，不做任何改变宏关系的"修复"。

早先版本里的让步动作（阵列重折、关系翻转、并拢）保留为可选的非严格模式（--concessions），只用于将来"允许重折"的变体题。

步骤

  • 意图提取：同尺寸、对齐、相近的宏并成刚性块（同类 30 µm 内，异类仅贴合时）；包住外来宏的块拆成行/列段；贴边 = 距核心边 ≤ 0.6 µm；记录每条通道和边缘留白的原宽。
  • 约束图（FLOORIST）：每对块一个关系，斜对角取归一化间距大的轴；H/V 图传递约简 = 通道。此后关系不再改变。
  • 可行性：逐轴最长路径（边权 = 尺寸 + 该通道适用的客户最小值 cmin 或 cpin，贴合块内为原间隙，到边为 cedge 或 0）≤ 目标外框；引脚：每边空闲轨道数（边长 − 贴边宏正前方 − 角落）≥ 引脚数 × 2 轨。先用同一套规则校验 F0，不合规的 F0 不能作为 case。
  • 定位 LP（HiGHS，逐轴）：差分约束 + 贴边等式 + 边缘留白下限；目标 = 每条通道相对 max(下限, s·g0) 的相对偏差的凸分段线性罚（超过 20% / 50% 后斜率 2 / 4）+ 小权重的仿射目标位移（IBM 留白再分配规则的 LP 形式）；结果对齐网格。
  • 引脚合法化：每个引脚的目标 = 原位置按边长比例缩放，换算成轨道号；边上的空闲轨道段扣掉贴边宏正前方和角落；在轨道号空间做保序的前向/后向单调投影（相邻 ≥ 2 轨），到不动点为止；容量不足即不可行。这是 Synopsys 专利"比例缩放 + 间隙再分配、保持边/序/对齐"的实现。
  • 校验与度量：逐条检查上述标准；输出关系保持率（恒 100%）、贴边保持、通道偏差、宏位移、引脚同序率与平均滑动。s* 用二分求得（步长 0.1%）。
